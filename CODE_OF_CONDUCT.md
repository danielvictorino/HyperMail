# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. All participants — contributors, maintainers, reviewers, and anyone interacting in project spaces (issues, pull requests, discussions) — are expected to follow it.

The full text is available at the link above and via `https://www.contributor-covenant.org/version/2/1/code_of_conduct.txt`.

## Reporting

If you believe someone is violating the Code of Conduct, please report it privately through GitHub's [private security advisory flow](https://github.com/danielvictorino/HyperMail/security/advisories/new) or by opening a private issue. Reports are reviewed on a best-effort basis by project maintainers; public call-outs are discouraged.

We do not publish a project email address — all reports should go through GitHub to preserve contributor privacy and provide a clear audit trail.
