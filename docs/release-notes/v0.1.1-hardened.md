# HyperMail v0.1.1-hardened

Five-day hardening pass on the v0.1.0 foundation. Focus: close the security, reliability, and test-coverage gaps before widening dogfooding.

## Security

- **Content-Security-Policy** on every renderer load — meta tag + runtime header via `session.defaultSession.webRequest.onHeadersReceived`. Dev-aware (allows Vite HMR origin + `unsafe-eval` only when `VITE_DEV_SERVER_URL` is set).
- **Electron window hardening**: `sandbox: true`, `contextIsolation: true`, `nodeIntegration: false`, `webSecurity: true`, `allowRunningInsecureContent: false`.
- **IPC input validation**: 10 mutating channels validated via zod schemas in `src/shared/ipc-contracts.ts`. Rejections surface as `IpcValidationError` and never reach domain code.
- **URL allowlist**: `shell.openExternal` and `will-navigate` only accept `https:` and `mailto:`. `file:`, `javascript:`, `http:` are dropped.

## Reliability

- **OAuth refresh**: jittered exponential backoff (1s / 2s / 4s), single-flight lock by refresh token, and correct error classification — only terminal OAuth error codes (`invalid_grant` etc.) clear the stored session; transient 5xx / 429 / network failures retry instead of signing the user out.
- **Gmail API retry**: `gmailJson` / `gmailModify` retry on 429 and 5xx, honoring `Retry-After`.
- **Dexie v3 migration**: `.upgrade()` backfills `snoozedUntil: null` and `unsubscribedAt: null` on existing threads. New `deleteAccountCascade` transactionally purges one account across all seven tables.

## Tests

- 13 → 20 test files, 43 → **107 tests**.
- New coverage: OAuth refresh classification + fixtures, IPC schema rejection + hostile payloads (prototype pollution, oversized strings, array/scalar confusion, `javascript:` URLs), Gmail retry end-to-end, modifier-queue persist→kill→restart, keyboard dispatcher (chord resolution, focus-scope, conflict precedence), Dexie cascade delete, OAuth state-tampering probe.

## Perf / DX

- **Vite bundle chunking**: vendor chunks for React, TanStack, Tiptap, Dexie, Zustand, UI utilities. App chunk dropped from 497 kB → 112 kB — updating app code no longer invalidates vendor caches.
- **Source maps**: `"hidden"` in prod (kept for crash symbolication, not exposed via `sourceMappingURL`).
- **TypeScript strict**: added `noUncheckedIndexedAccess` + `noImplicitOverride`. Zero fallout.
- **Renderer memoization**: `ThreadRow` now `React.memo`'d with stable `useCallback` handler. Cuts re-renders of off-window rows when parent state (search, focus nonces) changes.

## Known gaps (deliberately deferred)

- `downloadGmailAttachment` overload in `electron/gmail/google-mail-service.ts:487–491` — main.ts uses an `as unknown as` cast to work around a signature bug. Functional, ugly.
- Dexie v1→v2→v3 migration fixture test (the upgrade callback is in place and typechecked, but no end-to-end migration test against a seeded v1 DB).
- `exactOptionalPropertyTypes` not enabled — it cascades broadly; worth a separate audit pass.
